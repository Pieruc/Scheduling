\section{Work breakdown}
\label{sec:wbs}
% TODO: one paragraph per group of activities.
\begin{itemize}
  \item \textbf{Analysis and documentation}: domain, requirements and architecture decisions,
        ProblemSpec and API contracts; documentation is kept up to date until the delivery.
  \item \textbf{Data and AI}: instance generator and benchmark converters, dispatcher and
        EDD/ATC baselines, CP-SAT teacher and dataset, pilot model, M1 context model, AI service,
        generalisation experiments.
  \item \textbf{Backend and DB}: MySQL schema and Flyway migrations, security and CRUD, planning
        and AI client, decisions, execution, KPIs and audit, public API and events.
  \item \textbf{Frontend}: mockups and user flows, React setup, orders and graph editor, Gantt
        view and plan review, KPI dashboard.
  \item \textbf{Integration, evaluation and delivery}: Docker Compose and end-to-end integration,
        experimental evaluation, testing, final documentation review, presentation.
\end{itemize}
